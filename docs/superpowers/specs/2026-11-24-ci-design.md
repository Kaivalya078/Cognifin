# Phase 5.2 — CI

Date: 2026-11-24 · Branch: `phase-5-lint` · Size: small project

**Intent:** no CI exists. Every push/PR should prove lint, unit tests and the cheap evals still
pass, at zero cost (no paid calls, no 2.3 GB index in CI).

**Approaches:** (a) full evals in CI with the R2 index + OpenAI key — rejected (cost, stale
tarball); (b) **lint + unit tests + offline evals on a committed 2 MB financials snapshot —
picked (approved)**; heavy evals run locally (piece 3).

**Design (my calls, approved)**
- `.github/workflows/ci.yml`, on push to `main` and pull_request; jobs `backend` (Python 3.13)
  and `frontend` (Node 22) in parallel.
- Backend: CPU-only torch (`--extra-index-url https://download.pytorch.org/whl/cpu`), pip cache,
  Hugging Face model cache; `ruff check .`; `pytest tests/test_*.py`; copy
  `tests/fixtures/financials.duckdb` to `index_cache/`; `eval_financials --min-precision 100
  --min-coverage 93.1`; `eval_router --strict`; both tables appended to `$GITHUB_STEP_SUMMARY`.
- Gates: exit non-zero below today's numbers (100% precision, 93.1% coverage, 41/41 router).
- Snapshot refresh after a financials rebuild: `cp index_cache/financials.duckdb tests/fixtures/`.
- Frontend: `npm ci`, `npm run lint` (all 11 current findings fixed first; the two
  setState-in-effect errors read carefully), both `node` check scripts, build with a placeholder
  `https://` API base.
- Verified by the user pushing the branch and reading the Actions run together.
